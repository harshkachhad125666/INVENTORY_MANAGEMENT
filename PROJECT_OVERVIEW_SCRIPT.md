## Part 3: Frontend Walkthrough

[Action: Show the website dashboard, inventory page, and billing terminal]

"This is the frontend of my project. It is built using React, TypeScript, Vite, and Tailwind CSS.

Here, the dashboard shows business insights like revenue, profit, inventory value, low-stock alerts, sales chart, and top-selling products.

In the Product Catalog section, users can view products, add new products, edit product details, delete products, and manage stock quantity.

In the POS Billing Terminal, users can select products, add them to cart, generate bills, and complete checkout."

## Part 4: Backend & APIs

[Action: Open VS Code and briefly show the project folder, server file, and routes folder]

"For the backend, I have used Node.js and Express.js.

The backend handles all API requests for inventory, billing, and analytics. The main API routes are inventory APIs for product management, billing APIs for invoice generation, and analytics APIs for dashboard data.

When a user performs any action on the frontend, the frontend sends a request to the backend, and the backend processes the request and communicates with the database."

## Part 5: Database Overview & Deployment

[Action: Show Supabase console or database schema, then show deployed Vercel link]

"For the database, I have used Supabase with PostgreSQL.

The main database tables are products, invoices, invoice_items, and profiles. The products table stores product details and stock quantity. The invoices and invoice_items tables store billing records.

During checkout, the system creates an invoice and automatically reduces the product stock. This keeps inventory data accurate.

The project is deployed on Vercel, so it can be accessed online using the live URL."
